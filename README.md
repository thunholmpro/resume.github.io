# Robin Thunholm — Portfolio v3

Static HTML/CSS/JS portfolio for GitHub Pages.

## Update your existing site

Upload `index.html`, `assets/` and (optionally) this README to the root of your existing `thunholmpro/resume.github.io` repository. GitHub Pages should use `main` and `/(root)`. Do not upload the containing `robin-portfolio-v2` folder.

## Custom 3D icons

Replace each `<div class="icon-3d-slot" data-icon-key="...">...</div>` in `index.html` with your own PNG/WebP/AVIF asset or a `<model-viewer>`/canvas later. Current slots are intentional placeholders, not final 3D artwork.

## Certification

Certification in Creative Strategy, issued by Motion, completed in 2026, is included in the education and certifications timeline.

## Animation

Scroll reveals, hover tilt, border glows and magnetic buttons use CSS/vanilla JS with touch and reduced-motion fallbacks. No framework or build pipeline needed.
